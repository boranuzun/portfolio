A personal homelab environment used for experimenting with virtualization, containers, and self-hosted services.

## Hardware

- **HP EliteDesk 800 G3 SFF** — Intel Core i7-7700, 32 GB RAM, 2 × 8 TB HDD
  - Running **Proxmox VE** — hosting LXC containers and VMs for experimentation
  - Services: Jellyfin, TrueNAS, Home Assistant, and more
- **GMKTEC G3 Plus** — Intel N150, 16 GB RAM, 1 TB SSD
  - Running **Ubuntu 24.04 Server** — hosting multiple services via Docker Compose

## What I Run

- **Media:** Jellyfin for media streaming
- **Storage:** TrueNAS for network-attached storage
- **Home Automation:** Home Assistant for smart home management
- **Containers:** Various Docker Compose stacks for self-hosted services
- **VMs & LXC:** Regular experimentation with different operating systems and configurations

## What I Learn

This homelab serves as a hands-on playground for developing skills in systems administration, virtualization, networking, and container orchestration — complementing the more structured IaC approach from my [Bachelor's thesis](/projects/bachelor-thesis).
