A team-based development mandate for the accounting firm Comptarial to build a secure digital platform for client document exchange. The project was managed using an Agile (Scrum) framework to ensure rapid development and iterative feature delivery.

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Laravel, PHP
- **Database:** MySQL
- **Storage:** Infomaniak Swiss Backup (S3 compatible)

## Key Features

- **Secure Document Exchange:** Allowing clients and accountants to securely upload, manage, and share sensitive financial documents.
- **Agile Development:** Developed in a team environment using Scrum methodologies, focusing on iterative delivery and continuous feedback.
- **Cloud Storage Integration:** Leveraged Infomaniak's Swiss Backup S3-compatible object storage for reliable and compliant data persistence.
